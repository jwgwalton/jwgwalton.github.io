Getting Started with Transformer Architectures

January 15, 2024 12 min read
Transformers NLP Tutorial

Transformer architectures have revolutionized natural language processing and are now expanding into computer vision, audio processing, and more. In this comprehensive guide, we'll break down how transformers work and how to implement them effectively.

The Problem Transformers Solve

Before transformers, sequence modeling was dominated by RNNs and LSTMs. While effective, these architectures had fundamental limitations:

  • Sequential processing: Can't parallelize across the sequence
  • Limited context: Difficulty capturing long-range dependencies
  • Vanishing gradients: Training instability on long sequences

Transformers address all of these issues through a revolutionary mechanism: attention.

The Attention Mechanism

At its core, attention allows the model to focus on relevant parts of the input when processing each element. Think of it like highlighting important words when reading a sentence.

Self-Attention in Detail

Self-attention computes three vectors for each token:

  • Query (Q): What am I looking for?
  • Key (K): What do I contain?
  • Value (V): What information do I represent?

The attention formula is elegantly simple:

Attention(Q, K, V) = softmax(QK^T / √d_k)V

Let's implement this in PyTorch:

import torch
import torch.nn as nn
import math

class SelfAttention(nn.Module):
    def __init__(self, embed_dim):
        super().__init__()
        self.embed_dim = embed_dim
        
        # Linear layers to create Q, K, V
        self.query = nn.Linear(embed_dim, embed_dim)
        self.key = nn.Linear(embed_dim, embed_dim)
        self.value = nn.Linear(embed_dim, embed_dim)
        
    def forward(self, x):
        # x shape: (batch, seq_len, embed_dim)
        Q = self.query(x)
        K = self.key(x)
        V = self.value(x)
        
        # Compute attention scores
        scores = torch.matmul(Q, K.transpose(-2, -1))
        scores = scores / math.sqrt(self.embed_dim)
        
        # Apply softmax
        attention_weights = torch.softmax(scores, dim=-1)
        
        # Apply attention to values
        output = torch.matmul(attention_weights, V)
        return output

Multi-Head Attention

Instead of one attention mechanism, transformers use multiple "heads" that can focus on different aspects:

  • One head might focus on syntactic relationships
  • Another might capture semantic meaning
  • Others might handle positional or contextual information
class MultiHeadAttention(nn.Module):
    def __init__(self, embed_dim, num_heads):
        super().__init__()
        self.embed_dim = embed_dim
        self.num_heads = num_heads
        self.head_dim = embed_dim // num_heads
        
        self.query = nn.Linear(embed_dim, embed_dim)
        self.key = nn.Linear(embed_dim, embed_dim)
        self.value = nn.Linear(embed_dim, embed_dim)
        self.output = nn.Linear(embed_dim, embed_dim)
        
    def forward(self, x):
        batch_size, seq_len, _ = x.shape
        
        # Create Q, K, V and split into heads
        Q = self.query(x).view(batch_size, seq_len, self.num_heads, self.head_dim)
        K = self.key(x).view(batch_size, seq_len, self.num_heads, self.head_dim)
        V = self.value(x).view(batch_size, seq_len, self.num_heads, self.head_dim)
        
        # Transpose for attention computation
        Q = Q.transpose(1, 2)  # (batch, heads, seq_len, head_dim)
        K = K.transpose(1, 2)
        V = V.transpose(1, 2)
        
        # Compute attention
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.head_dim)
        attention = torch.softmax(scores, dim=-1)
        
        # Apply attention to values
        out = torch.matmul(attention, V)
        
        # Concatenate heads and apply output projection
        out = out.transpose(1, 2).contiguous().view(batch_size, seq_len, self.embed_dim)
        return self.output(out)

Positional Encoding

Since transformers process all tokens in parallel, they need a way to understand position. Positional encoding adds position information to the embeddings: 

class PositionalEncoding(nn.Module):
    def __init__(self, embed_dim, max_len=5000):
        super().__init__()
        
        # Create positional encoding matrix
        pe = torch.zeros(max_len, embed_dim)
        position = torch.arange(0, max_len).unsqueeze(1)
        div_term = torch.exp(torch.arange(0, embed_dim, 2) * 
                           -(math.log(10000.0) / embed_dim))
        
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        
        self.register_buffer('pe', pe.unsqueeze(0))
        
    def forward(self, x):
        return x + self.pe[:, :x.size(1)]

The Full Transformer Block

A complete transformer encoder block combines:

  1. Multi-head attention
  2. Add & Norm (residual connection + layer normalization)
  3. Feed-forward network
  4. Another Add & Norm
class TransformerBlock(nn.Module):
    def __init__(self, embed_dim, num_heads, ff_dim, dropout=0.1):
        super().__init__()
        
        self.attention = MultiHeadAttention(embed_dim, num_heads)
        self.norm1 = nn.LayerNorm(embed_dim)
        self.norm2 = nn.LayerNorm(embed_dim)
        
        self.feed_forward = nn.Sequential(
            nn.Linear(embed_dim, ff_dim),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(ff_dim, embed_dim)
        )
        
        self.dropout = nn.Dropout(dropout)
        
    def forward(self, x):
        # Multi-head attention with residual
        attn_out = self.attention(x)
        x = self.norm1(x + self.dropout(attn_out))
        
        # Feed-forward with residual
        ff_out = self.feed_forward(x)
        x = self.norm2(x + self.dropout(ff_out))
        
        return x

Training Tips

Learning Rate Scheduling

Transformers benefit from warmup followed by decay: 

from torch.optim.lr_scheduler import LambdaLR

def get_lr_scheduler(optimizer, warmup_steps, d_model):
    def lr_lambda(step):
        step = max(step, 1)
        return (d_model ** -0.5) * min(step ** -0.5, 
                                       step * warmup_steps ** -1.5)
    
    return LambdaLR(optimizer, lr_lambda)

Regularization

  • Dropout: Apply to attention weights and feed-forward outputs
  • Label smoothing: Prevents overconfidence in predictions
  • Weight decay: L2 regularization on model parameters

Common Variants

BERT (Bidirectional Encoder)

Uses only the encoder stack, bidirectional attention. Best for:

  • Text classification
  • Named entity recognition
  • Question answering

GPT (Decoder-only)

Uses causal (left-to-right) attention. Best for:

  • Text generation
  • Language modeling
  • Few-shot learning

T5 (Encoder-Decoder)

Full transformer architecture. Best for:

  • Translation
  • Summarization
  • Any sequence-to-sequence task

Practical Considerations

Memory Usage

Attention is O(n²) in sequence length. For long sequences:

  • Use gradient checkpointing
  • Consider sparse attention patterns (Longformer, BigBird)
  • Implement sliding window attention
  • Use mixed precision training (FP16/BF16)

Optimization

  • Use torch.compile() for PyTorch 2.0+
  • Implement FlashAttention for faster training
  • Cache key-value pairs during inference

Getting Started

The best way to learn transformers is to implement them. I recommend:

  1. Start with the code examples above
  2. Read the original "Attention is All You Need" paper
  3. Experiment with small datasets (like IMDB for sentiment analysis)
  4. Use pre-trained models from HuggingFace for real applications
  5. Gradually increase complexity as you understand the basics

Conclusion

Transformers have become the foundation of modern AI, and understanding them is essential for any AI engineer. While the architecture seems complex at first, it's built on simple, elegant ideas: attention, residual connections, and layer normalization.

Start small, experiment often, and don't be afraid to implement things from scratch. The best way to understand transformers is to build them yourself!
